# Manuscript

`main.tex` is the canonical scientific document and `main.pdf` is its compiled
form. This directory is self-contained: every file the paper includes lives
here, so the folder can be uploaded to Overleaf as-is.

## Overleaf

Upload (or git-sync) this directory as a new project. Set the compiler to
**pdfLaTeX**, TeX Live 2024 or later, and `main.tex` as the main document.
REVTeX 4.2, `mathalpha` (Boondox calligraphic), `graphicx`, and `microtype`
are all in Overleaf's TeX Live image. There is no `.bib` file; the
bibliography is written in the source.

Required for compilation:

- `main.tex`
- `figures/figure-1-response-rules.pdf`
- `figures/figure-2-nutrient-landscape.pdf`
- `figures/figure-3-case-1-validation.pdf`
- `figures/figure-4-macroscopic-observables.pdf`
- `figures/figure-5-foraging-observables.pdf`
- `figures/figure-6-information-observables.pdf`
- `figures/figure-remaining-cases.pdf`

Leave out LaTeX intermediates (`*.aux`, `*.log`, `*.fls`, `*.fdb_latexmk`,
`*.bak`) and `main.pdf`. Video legends are in
`../sources/notes/supplementary_video_legends.md`; the videos themselves are
generated under `../outputs/simulations/population_release/videos/` and are
journal supplementary material, not Overleaf assets.

Compile locally from this directory with `latexmk -pdf main.tex`. Temporary
LaTeX files should not be committed; `main.pdf` is retained for collaborators
who do not have the REVTeX toolchain installed.

## Figures

- `figures/figure-1-response-rules.pdf`: conceptual map of the nine mechanisms;
- `figures/figure-2-nutrient-landscape.pdf`: the single cosine mode the
  comparison runs on, and the three requirements that select it, written by
  `../analysis/manuscript/figure_2_nutrient_landscape/`;
- `figures/figure-3-case-1-validation.pdf`: Case 1 numerical validation;
- `figures/figure-4-macroscopic-observables.pdf`: net polarity, centroid,
  spread and pulse shape along all three paths, written by
  `../analysis/manuscript/figure_4_macroscopic_observables/`;
- `figures/figure-5-foraging-observables.pdf`: the drift/mobility pair read
  off one landscape mode, nutrient uptake, the two relaxation clocks, and the
  divergence between strategies, written by
  `../analysis/manuscript/figure_5_foraging_observables/` from
  `../model/parameters/foraging.toml`;
- `figures/figure-6-information-observables.pdf`: finite-lag navigation and
  information (appendix: tracking one cell), written by
  `../analysis/manuscript/figure_6_information_observables/` from
  `../model/parameters/navigation.toml`;
- `figures/figure-remaining-cases.pdf`: appendix sheet of Cases 2--9, copied
  from `../outputs/simulations/population_release/figures/supplementary/figure-s01-cases-2-9-summary.pdf`
  by `python -m simulations.population_release.run compare`.

Figure 1 is drawn by `../analysis/manuscript/figure_1_response_rules/` (its
intermediate SVG stays in `../outputs/`). Figures 2--6 and the remaining-cases
sheet are generated by the simulation pipeline. Additional scientific figures
are indexed in `../outputs/simulations/population_release/README.md` (local, not in Git).
